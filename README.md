# 충전쉼표 (ChargeRest)

> 전기차의 실시간 배터리·전비 데이터로 충전 계획을 자동으로 세우고, 충전하는 20~40분을 시트·공조·조명이 함께 맞춰지는 '차 안의 휴식 시간'으로 바꿔주는 Pleos Connect용 EV 충전 컨시어지 앱

현대자동차그룹 차량용 앱 개발 공모전 출품작입니다. 이 저장소에는 제출용 APK와 소개 문서만 있습니다.

| 항목 | 내용 |
|---|---|
| 플랫폼 | Pleos Connect (Android Automotive OS, API 34) |
| APK | [`apk/sedoll_충전쉼표_release.apk`](apk/) |
| 버전 | 0.1.0 (최소 API 28, 타깃 API 34) |
| 사용 SDK | Pleos Vehicle · NaviHelper · FusedLocation · TextToSpeech |
| 외부 데이터 | 공공데이터포털 '한국환경공단 전기자동차 충전소 정보' API |

## 1. 기획

### 주목한 순간
- 장거리 주행 중 "이 배터리로 목적지까지 갈 수 있을까?"라는 불안
- 겨우 찾아간 충전소가 만석이거나 충전기가 고장 나 있을 때의 헛걸음
- 급속충전기 앞에서 할 일 없이 보내는 20~60분

### 기존 해결책의 한계
- 충전 앱·스마트폰 내비는 차량의 실시간 잔량과 실제 전비를 직접 알 수 없어 사용자 입력이나 평균값으로 추정합니다.
- 충전소를 찾은 뒤에도 차량 내비에 경유지를 따로 입력해야 하고, 가는 동안 자리가 차도 알 수 없습니다.
- 충전 중 시간은 '휴대폰을 보며 기다리는 시간'으로 방치되어 있습니다.

### 해결 방향
충전 계획(언제·어디서)과 충전 경험(무엇을 하며 기다리나)을 **차량 데이터와 차량 기능**으로 한 번에 해결합니다.

### 주요 기능

**① 스마트 충전 플랜 (주행 중)**
- 차량의 실시간 잔량(SoC)과 전비로 '도착 시 예상 잔량'을 계산합니다. 차량이 전비를 주지 않으면 순간·충전 후·누적 전비 순으로 대체합니다.
- **배터리 부족 미리 알림**: 도착 예상 잔량이 10% 미만(경로가 없으면 잔량 15% 이하)이 되면 차가 먼저 음성으로 알리고, 지금 잔량으로 갈 수 있으면서 빈자리가 있는 급속충전소를 경로에서 덜 돌아가는 순으로 3곳 제안합니다.
- 한 번의 터치로 차량 내비에 경유지로 추가합니다.
- **가는 길 빈자리 재확인**: 경유지 충전소를 1분마다 다시 조회해, 도착 전에 자리가 모두 차거나 충전기가 점검·통신이상이 되면 음성으로 알리고 가까운 빈 충전소로 원탭 교체합니다.

**② 충전쉼표 모드 (충전 중 · 핵심 기능)**
- 충전 시작을 차량 신호(충전구·충전 스위치)로 자동 감지해 휴식 모드를 엽니다.
- 휴식 프리셋: 낮잠 / 집중 업무 / 아이와 함께 — 시트 리클라인, 공조 온도·풍량, 앰비언트·실내 조명을 한 번에 맞춥니다. 나만의 프리셋을 추가·편집·삭제할 수 있습니다.
- **충전 진행률 조명**: 앰비언트 조명이 충전 정도에 따라 빨강 → 주황 → 초록으로 바뀝니다.
- **스마트 기상**: 완료 5분 전 조명을 서서히 밝히고 음성으로 알린 뒤, 시트·공조·조명을 원래대로 되돌리는 '출발 준비'를 실행합니다.
- 예상 완료 시각과 목표 충전량(80/90/100%)을 표시하고, 목표를 바꾸면 차량 충전 한도도 함께 설정합니다.

**③ 충전기 고장 감지·신고**
- 충전구가 열려 있는데 3분 넘게 충전이 시작되지 않거나 도중에 멈추면 고장을 의심해 음성으로 알립니다.
- 충전소·충전기 번호·증상·시각을 담은 신고 내용을 자동으로 만들고, 운영기관 고객센터 → 전기차 충전기 통합 콜센터(1661-9408) → 정부민원안내콜센터(110) 순으로 원탭 전화 연결합니다. 무단 발신을 막기 위해 통화 버튼은 운전자가 직접 누릅니다.
- 빈자리가 있는 가까운 급속충전소로 바로 길안내합니다.

### 스마트폰 앱과 무엇이 다른가

| 항목 | 스마트폰 앱 | 충전쉼표 |
|---|---|---|
| 배터리 잔량·전비 | 사용자 입력·평균 추정 | 차량 실시간 데이터 |
| 충전 필요 알림 | 운전자가 직접 확인 | 도착 예상 잔량으로 차가 먼저 알림 |
| 경유지 등록·교체 | 폰 내비에서 따로 조작 | 차량 내비에 원탭 추가, 자리가 차면 원탭 교체 |
| 충전 감지 | 사용자가 직접 시작 | 차량 충전 신호로 자동 시작 |
| 충전 진행 확인 | 앱을 열어 확인 | 실내 조명 색으로 한눈에 |
| 고장 대응 | 번호를 찾아 직접 설명 | 차량 신호로 감지, 신고 내용 자동 작성 |
| 충전 중 경험 | 휴대폰 화면 보기 | 시트·공조·조명이 함께 바뀌는 차량 공간 경험 |

### 사용 시나리오
1. **주말 가족 여행** — 목적지를 설정하자 "도착 시 예상 잔량 8%" 음성 안내 → 추천 충전소를 원탭으로 경유지 추가 → 가는 도중 그 충전소가 만석이 되자 가까운 빈 충전소로 원탭 교체 → 충전 시작과 함께 '아이와 함께' 프리셋, 조명이 주황에서 초록으로 → 완료 5분 전 조명이 밝아지며 출발 준비
2. **퇴근길 충전** — 잔량 15%에서 차가 먼저 가까운 빈 충전소를 알려주고, 30분 동안 직접 만든 휴식 프리셋으로 쉼
3. **충전기 고장** — 커넥터를 꽂았는데 3분째 충전이 안 됨 → 신고 내용 자동 작성 → 운영사 고객센터 원탭 연결 → 근처 빈 충전소로 길안내

- Kotlin 2.2 · Jetpack Compose · Coroutines/StateFlow · Gradle 9.5 / AGP 9.3
- 구조: 차량 상태 계층(Vehicle·NaviHelper·FusedLocation SDK) → 판단 로직(도착 잔량, 배터리 부족, 빈자리 변화, 고장 감지, 완료 예측) → 화면
- 판단 로직은 Android 의존성이 없는 순수 Kotlin으로 분리해 단위 테스트 57개로 검증했습니다.

## 3. 시연 방법

### 3-1. Pleos Connect 에뮬레이터 준비
1. Android Studio → **Tools > SDK Manager > SDK Update Sites** → `+`
   - Name: `Pleos Connect System Image`
   - URL (Windows/Linux): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
   - URL (Mac): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
2. **SDK Platforms** 탭 → **Show Package Details** → Android API 34의 **Pleos Connect system Image** 설치 → Android Studio 재시작
3. **Tools > Device Manager > Create device** → Form Factor **Automotive** → **Pleos Connect v2.1.0**
   - Advanced Settings: Default boot **Cold**, RAM **4 GB**
4. 에뮬레이터 실행

### 3-2. APK 설치·실행
```bash
adb install "apk/sedoll_충전쉼표_release.apk"
```
- 하단 앱 목록에서 **충전쉼표**를 실행합니다.
- 첫 실행 때 뜨는 위치 권한 창에서 **허용**을 누릅니다 (내비가 준비되지 않아도 현재 위치로 충전소를 찾기 위해 사용).
- 인터넷 연결이 필요합니다 (충전소 정보 조회).

### 3-3. 차량 상태 바꾸기 (Virtual Console)
```bash
adb forward tcp:8088 tcp:8088
```
브라우저에서 `http://127.0.0.1:8088/` → **Emulation Controls > EV Battery**에서 배터리 잔량(Battery SOC), 충전구(Charge Port), 충전 스위치(Charge Switch)를 바꿉니다. 값이 반영되려면 Virtual Console 페이지를 열어 둔 상태여야 합니다.

### 3-4. 기능별 시연 순서

| 기능 | 조작 | 기대 결과 |
|---|---|---|
| 배터리 부족 미리 알림 | Charge Port **Closed**, Battery SOC를 **15% 이하**로 | 홈 화면 맨 위에 "배터리가 12% 남았어요" 카드와 빈자리 있는 급속충전소 3곳, 음성 안내 |
| 원탭 경유지 추가 | 추천 충전소의 **경유지 추가** | 차량 내비에 경유지 요청, 홈 화면에 '가는 중인 충전소' 카드(빈자리 n/m, 확인 시각) |
| 빈자리 재확인·교체 | 오른쪽 '주변 급속충전소' **검색** → 빈자리 **0**인 곳을 **경유지 추가** | 곧바로 "자리가 모두 찼어요"와 대체 충전소 3곳 → **이곳으로 바꾸기**로 교체 |
| 충전쉼표 모드 자동 시작 | Charge Port **Open** → Charge Switch **On** | 충전쉼표 모드 화면이 자동으로 열림 |
| 휴식 프리셋 | 프리셋(낮잠 등) 선택, **+ 추가 / 편집 / 삭제** | 시트·공조·조명이 함께 바뀜, 나만의 프리셋 저장 |
| 충전 진행률 조명 | 충전 중 Battery SOC를 40 → 70 → 78 등으로 변경 | 앰비언트 조명 색이 빨강 → 주황 → 초록 |
| 스마트 기상·출발 준비 | Battery SOC를 목표(기본 80%) 직전으로 | 조명이 서서히 밝아지고 음성 안내, 시트·공조·조명 원위치 |
| 충전기 고장 감지·신고 | Charge Port **Open** + Charge Switch **Off** 상태로 3분 대기 | 고장 알림 창: 신고 내용 자동 작성, 충전기 번호 선택, 고객센터 원탭 전화(전화 앱에 번호 입력), 대체 충전소 길안내 |

> 충전소 빈자리는 실시간 데이터라 시점마다 빈자리 0인 충전소가 다릅니다.

| 대상 | 검증 내용 |
|---|---|
| 충전 계획 | 도착 잔량, 주행가능거리, 80% 이후 충전 속도 감소를 반영한 완료 시간, 용량·전비 대체 |

### 에뮬레이터 확인 (Pleos Connect v2.1)
- 배터리 12%에서 알림 카드와 추천 충전소(0.0km, 0.1km, 0.2km 순) 표시, 경유지 추가 시 차량 내비 연동
- 실제로 만석인 충전소를 경유지로 넣자 "자리가 모두 찼어요"와 대체 충전소가 뜨고, 교체 후 새 충전소 빈자리를 다시 확인
- 충전 진행에 따라 앰비언트 조명 색 변화(주황 → 초록), 완료 직전 밝기 단계적 상승
